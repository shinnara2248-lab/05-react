React : 화면을 작은 블럭으로 나눠 만드는 도구
컴포넌트 : 화면을 구성하는 작은 블럭 단위
JSX : 자바스크립트 안에서 화면의 모양을 만들어주는 문법
props : 부모가 가지고 있는 내용(변수, 메서드)을 자식 컴포넌트에 전달할떄 사용하는 상자
state : 화면이 기억해야하는 값, 값이 변경되면 화면에도 나타나야한다.
event : 웹앱에서 일어날 수 있는 사건들, 마우스 이벤트, 스크롤 이벤트

배열 : 여러개의 데이터를 저장할 때 사용한다. 순서로 체크한다.
오브젝트 : 여러개의 데이터를 저장할 때 사용한다. 속성명으로 체크한다.
구조분해할당 : 배열이나 오브젝트의 데이터를 분해해서 새로운 변수로 할당해주기
출력방법 : map, filter, find

1. Javascript 배열, 객체, 구조분해할당
2. 함수, 매개값, 리턴
3. JSX4
4. props
5. state
6. event
7. map
8. filter
